# Experiment E3 (user calibration) on the pilot data (evaluate_calibration.py), run on 2026-11-23

MECHANICS CHECK ONLY, NOT an E3 result. There is one complete person (u99; u01 is the same hand and has only
open_palm), so no other user can serve as the population: the script falls back to "pilot mode", where the
population is the same person (two halves of the non-calibration clips by clip number). Calibration then has
nothing to fix, and the defaults were read off this person's clips in the first place. E3 needs at least three
users with every gesture recorded at least twice (one clip for the calibration, the rest for the test).

Reproduce with:  .venv\Scripts\python.exe evaluate_calibration.py
                 .venv\Scripts\python.exe calibration.py --user u99 [--clip 1|2|3]   (profile only)
(Python 3.13.11, numpy 2.5.5, scikit-learn 1.9.1)

What calibration does (calibration.py, TEAM_BRIEF A.11 and D.4 item 14): clip 1 of every gesture plays the
role of the start-up calibration. Stability thresholds from the palm speed / pose change of the held gestures
(only raised); rule finger thresholds fitted on the steadiest second of each held gesture, mixed half and half
with the population and kept within +-30 %; confidence thresholds only lowered (10th percentile of the right
answers, floor 0.5); tau_on = 0.3 x the slower calibration swipe (at least 2 x v_max), tau_off = tau_on / 2;
every value within 0.5 to 2 times its default. Every held gesture is first checked with the uncalibrated rules.

Findings
1. The chain runs end to end on real clips: all four recorded held gestures pass the check, both swipes pass,
   point is reported as missing and keeps the defaults.
2. All five variants (rules / SVM, with and without calibration) are at 100 % on the test clips, so pilot mode
   shows only that calibration does not break anything here; it cannot show a benefit.
3. Calibration clip matters: with clip 1, 2 or 3 of u99 the stability noise of one 2-second hold gives v_max
   0.26, 0.15 and 0.24 (before the "only raise" rule), i.e. one short hold is a noisy sample. With v_max 0.15
   some frames of the same person's still clips (fastest frame up to 0.18) would no longer count as still.
   This is why v_max and pose_max are only raised (defaults are kept for calm users).
4. Swipe thresholds: calibrated tau_on 1.23 (default 1.00). Both values are reached by all 9 other swipe clips
   and by none of the 19 static test clips, so on this person both separate swipes from still hands.
Limits: one person, near distance, plain background, bright light; no point and no no_gesture data.
